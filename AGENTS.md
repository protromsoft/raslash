# Expo

Bu proje **Expo SDK 54** kullanır (`expo ~54.0.30`, React Native 0.81.5, React 19.1.0).

Kod yazmadan önce sürüme birebir uyan dokümanı oku:
https://docs.expo.dev/versions/v54.0.0/

Expo son sürümlerde çok değişti; en güncel doküman (v57) bu projeye uymaz.
`package.json` içindeki sürümü değiştirirken bu dosyadaki bağlantıyı da güncelle.
